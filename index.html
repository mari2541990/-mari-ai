IPHONE AUTOMATION GUIDE

To make MARI AI run phone actions, create them in Apple's Shortcuts app. iOS does not let a normal webpage control every app or phone setting.

  1. Open Apple Shortcuts.
  2. Tap + and add an action such as Open App, Show Notification, or Add New Reminder.
  3. Name the shortcut “MARI”.
  4. Say “Hey Siri, MARI” to run it.
  5. For a Home Screen icon: open shortcut details → Add to Home Screen.

ASSISTANT NOTE

This is a free personal dashboard prototype, not a full AI model. It can manage local task notes and open web services. Live AI chat and deeper phone automation require a supported AI service or Apple Shortcuts permissions.
